## Data Source Priority & Fallbacks

The vulnerability calculation uses multiple data sources with fallback options:

### Poverty Data (Priority Order):
1. **PIP (Poverty and Inequality Platform)** - Primary source
2. **World Bank Poverty Rate** - Fallback
3. **Our World in Data (poverty_below_3usd)** - Secondary fallback

### Stunting Data (Priority Order):
1. **WHO Stunting Rate** - Primary source
2. **Global Data Lab Child Stunting Rate** - Fallback

### Health Vulnerability (Multiple Indicators):
- Uses the highest applicable score from:
  - Under-5 Mortality (Global Data Lab)
  - Infant Mortality (Global Data Lab)
  - Child Wasting Rate (Global Data Lab)

## Notes

- **Vulnerability scores are calculated for all countries** even when some data is missing, using available data and default values for missing components.
- Many countries with missing data are small island nations, territories, or countries with limited data collection capacity.
- Some countries (like North Korea, Cuba, some Middle Eastern countries) have missing data due to limited international data sharing.
- WFP market data is only available for countries where WFP operates programs, which explains why many developed countries are missing this data.
- **New data sources** (Global Data Lab, USDA, Our World in Data) have varying coverage and may have different country lists than traditional sources (FAO, World Bank).
- **Historical hunger outbreak data** is manually curated and only includes countries with documented major crises, so most countries will have "No outbreak" rather than "missing data."
- **Regional classification** is assigned to all countries based on geographic and economic criteria, so no countries are missing this data.
