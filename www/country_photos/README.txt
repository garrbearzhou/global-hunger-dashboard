Country and region photos for the Country Details page
=======================================================

To show a photo for a country on the Country Details page, add an image file here with the country name (spaces as underscores). Examples:

  Angola.jpg
  South_Africa.jpg
  United_States.jpg

Supported formats: .jpg, .jpeg, .png, .gif

The app will display the image in the "Country profile" banner when that country is selected. If no file is found, the banner still shows the country name and icon.
