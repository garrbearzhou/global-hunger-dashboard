# Quick Citation Adder

**To add a new citation, simply paste the URL below and I'll format it properly!**

## How it works:

1. **Paste your URL here** (in your message to me)
2. I'll extract the information and format it in APA style
3. I'll add it to the citations list in `app.R`
4. It will automatically appear on the website

## Examples of what you can paste:

- Data source URLs: `https://data.worldbank.org/indicator/SI.POV.DDAY`
- Research papers: `https://www.nature.com/articles/s41586-023-06221-2`
- Reports: `https://www.wfp.org/publications/global-report-food-crises-2025`
- Documentation: `https://www.fao.org/faostat/en/#data/FS`
- Any other reference material

## What I'll do:

1. Extract organization name from the URL
2. Generate an appropriate title
3. Format in APA citation style
4. Add it to the citations list
5. Show you a preview before adding
