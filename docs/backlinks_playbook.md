## 1. GitHub (do first)

### README
Repo README updated with live links at the top. After push, verify on:
https://github.com/garrbearzhou/global-hunger-dashboard

### Repository homepage (About box)
1. Open repo on GitHub → click **⚙️** next to About (right sidebar)
2. Set **Website** to: `https://globalhungerdashboard.com`
3. Optional description: `Interactive global hunger vulnerability map and country food security profiles`
4. Save

### Push README if not on GitHub yet
```bash
git add README.md WEBSITE_README.md docs/backlinks_playbook.md docs/seo_status.md
git commit -m "Add live dashboard links for SEO backlinks"
git push origin main
```
